# Data Inspection and Update of CTAmap for 2009–2024

## Province/City/County Count Display

![](/img/PICS/673f390f55505.png)

**Forestry Area (林区)** is one of China's administrative divisions. Its administrative status is the same as that of districts, county-level cities, counties, autonomous counties, banners, autonomous banners, and special districts. It is a county-level administrative division. There is currently only one — the Shennongjia Forestry Area, directly governed by Hubei Province.

**Special District (特区)** here refers to Liuzhi Special District, which is under the jurisdiction of Liupanshui City in western Guizhou Province. There is currently only one.

Therefore:

Province-level administrative units include: **Province, Municipality, Autonomous Region, Special Administrative Region**.

Prefecture-level administrative units include: **Prefecture-level City, Autonomous Prefecture, Prefecture, League**.

County-level administrative units include: **District, County-level City, County, Autonomous County, Banner, Autonomous Banner, Directly-governed County, Province-directly-governed City, Forestry Area, Special District**.

In addition, there are province-directly-governed counties and province-directly-governed cities. In the administrative-division hierarchy of the Ministry of Civil Affairs, they are not subject to custody or jurisdiction by any prefecture-level administrative division. They are county-level administrative divisions, not subject to custody or jurisdiction by prefecture-level administrative divisions, and are directly governed by province-level administrative divisions. They are independently established outside prefecture-level administrative divisions and are directly led and managed by the province or autonomous region where they are located. Therefore, province-directly-governed counties and province-directly-governed cities have **no prefecture-level administrative division** and are also county-level administrative divisions.

## Modify English Attributes to Be Fully Unified.

Previous attributes may have had extra spaces, making them look the same but actually be different values.

![](/img/PICS/673f392c7d310.png)

Because the Chinese hierarchy is completely correct, write code to implement a one-to-one correspondence:

```matlab
import arcpy

# Define workspace
workspace = r"F:\PAPER\SHENGSHIXIAN\shengshixian\shengshxiain.gdb"
arcpy.env.workspace = workspace

# Feature class name
feature_class = "T2011 County-level_ExportFeatures"

# Define county-level type mapping dictionary
type_mapping = {
    "District": "District",
    "Banner": "Banner",
    "County": "County",
    "Autonomous Banner": "Autonomous Banner",
    "County-level City": "County City",
    "Forestry Area": "Forestry Area",
    "Autonomous County": "Autonomous County",
    "Special District": "Special District",
    "Not Counted": None
}

# Function to update feature attributes
def update_type3(feature_class):
    count = 0
    with arcpy.da.UpdateCursor(feature_class, ["County-level Type", "TYPE_3"]) as cursor:
        for row in cursor:
            county_type = row[0]  # County-level Type
            if county_type in type_mapping:
                row[1] = type_mapping[county_type]  # Update TYPE_3
                cursor.updateRow(row)
                count += 1
    return count

# Execute update and display result
try:
    updated_count = update_type3(feature_class)
    print(f"Update complete, {updated_count} records updated in total.")
except Exception as e:
    print(f"Error during update: {str(e)}")
```
