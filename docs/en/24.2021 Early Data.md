# Province/City/County Administrative Division Data, Early 2021

Based on the administrative-division data already produced for early 2020 (see: https://www.shengshixian.com/pages/b8a988/), we proceed to produce the early-2021 administrative-division data.

## Hainan Sansha City

**Ministry of Civil Affairs Announcement on the State Council's Approval of Establishing Districts for Sansha City, Hainan Province**

　　Sansha City of Hainan Province establishes Xisha District and Nansha District. Xisha District of Sansha City administers the islands, reefs, and sea areas of the Xisha Islands, and on behalf administers the islands, reefs, and sea areas of the Zhongsha Islands. The Xisha District People's Government is seated on Yongxing Island. Nansha District of Sansha City administers the islands, reefs, and sea areas of the Nansha Islands. The Nasha District People's Government is seated on Zhubi Reef. Because the South China Sea islands are sparsely represented in the 1:1,000,000 National Fundamental Geographic Information data, the three districts cannot be further subdivided. Here, the entire Sansha City vector from Amap (AutoNavi) is used to replace the old vector. The boundary is delineated with reference to the 2022 Amap (AutoNavi) administrative-division boundaries, and the administrative-division codes are updated to early 2021.

## Other Modifications

### Time Attribute

Considering that this dataset has a time attribute, a `year` field is added to the attribute table (representing the year). 2021 represents the early-2021 vector, and so on:

![Time field](/img/PICS/62fc6137eca02.png)

### Division Code Field

In the county-level administrative-division data, for some regions (e.g., Zhongshan City, Dongguan City, Hong Kong, etc.) the county-level code is not the administrative code of the region. A `区划码` (division code) field and its corresponding `code` English field are added, with the field attribute set to Long Integer.

![Adjustment of division codes for areas without county-level units](/img/PICS/62fc8ce0b32f0.png)

In the prefecture-level administrative-division data, for some regions (e.g., Qionghai and Wenchang in Hainan Province) the administrative code is the county-level code. A `区划码` (division code) field and its corresponding `code` English field are added, with the field attribute set to Long Integer.

![Adjustment of division codes for areas without prefecture-level units](/img/PICS/62fc8c82ec9a1.png)

### Field Type

In the first version of the vector, the field type of the division code was Double. It is corrected in this version, and the division-code fields of the province, prefecture, and county vectors are all changed to Long Integer.

![](/img/PICS/62fc6077a4169.png)

The province-level vector's field names and arrangement are modified. The new field order of the province-level division is as follows:

| Place name | VAR_NAME   |
| -------- | ---------- |
| Province code   | FIRST_GID  |
| Province type   | FIRST_TYPE |
| ENG_NAME | year       |

### 2020 Division Data Modifications

The South China Sea islands are replaced with the Amap (AutoNavi) South China Sea islands data.

Administrative-division codes that were incorrect in some areas have been corrected.

The province, prefecture, and county vectors gained two additional fields: `year` and `区划码` (division code).

In the province, prefecture, and county vectors, the field containing the division code is set to Long Integer.

The English-name field of the prefecture-level data is renamed to `ENG_NAME`.

The field attributes and names of the province-level administrative-division data are reorganized.

### Website Modifications

Data download uses object storage to improve download speed (as fast as your network allows).

KML, GeoJSON, and other formats are removed; only SHP format data is retained for download.
