Administrative division data is important foundational geographic information data, but there are many problems with the administrative region data currently available on the market. Based on the above issues, I would like to produce a set of administrative-division data based on **authoritative administrative-division sources**, covering **a long time series from 1992 to 2024** (currently 2000–2024 completed), with **attributes compliant with the Ministry of Civil Affairs**, and **openly accessible**.

CTA_map is such a set of national long time-series province/city/county vector administrative-division data.
